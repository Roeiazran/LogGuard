# data/

Only this README and `fixtures/` are tracked by git.

| Path | Content | Tracked |
|---|---|---|
| `fixtures/` | Small synthetic logs used by tests and CI | Yes |
| `raw/` | Downloaded datasets (e.g. BGL) | No |
| `splits/` | Chronological train/val/test splits | No |

## BGL dataset

Source: Loghub, https://github.com/logpai/loghub (BGL). A download script with checksum verification will be added in `scripts/download_bgl.sh`.
Check the dataset's license and attribution requirements before redistributing any part of it.
